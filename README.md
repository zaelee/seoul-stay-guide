# 이태원 · 을지로 숙소 비교 가이드 (4인 / 7인)

이태원(용산구)과 을지로(중구·종로 인접) 지역의 **4인 기준** 및 **7인 기준(욕실 2개 이상)** 에어비앤비 숙소를 비교한 단일 HTML 페이지입니다.

- **전체 숙소 위치 대표 지도**: 상단 대화형 지도(Leaflet + OpenStreetMap)에 모든 숙소 번호와 1인당 가격 마커가 표시되며, 마커 클릭 시 대표 사진·주소·예약 링크 팝업이 열립니다.
- **대표 사진 및 주소**: 각 숙소의 에어비앤비 공식 대표 이미지, 구·동·인접 역세권 주소, 위도·경도 좌표 및 구글 지도 위치 바로가기가 포함되어 있습니다.
- **일정 전환 및 자동 링크**: `2026-12-04 (금) ~ 2026-12-05 (토)` 1박 기준과 `11월 평일 가성비` 기준을 전환할 수 있으며, 체크인/체크아웃 날짜 변경 시 모든 에어비앤비 바로가기 링크가 자동 갱신됩니다.
